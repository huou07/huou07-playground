## Architecture decision
The reference calls for a compact, custom personal dashboard. The portal is a small Python standard-library HTTP server serving static HTML/CSS/JS and read-only Linux metrics, with no frontend or backend package dependencies. It listens on loopback and, on the deployed host, the exact private IPv4 address assigned to `wg0`, with that socket bound to the WireGuard device. Applications remain separate services. The dashboard API exposes no privileged host operations or credentials; optional hardware readings are fed by separately confined systemd collectors.
